kind: bug
title: "attr_list: an empty attribute list `{: }` produces an invalid `:` attribute"
---
Our docs template generates headings like `# Title {: }` when a page has no custom classes (the template always emits the braces, sometimes with nothing inside). With `attr_list` enabled the output contains a broken attribute:

```python
>>> import markdown
>>> markdown.markdown("# Title {: }", extensions=["attr_list"])
'<h1 :>Title</h1>'
>>> markdown.markdown("Some paragraph\n{:}", extensions=["attr_list"])
'<p :>Some paragraph</p>'
>>> markdown.markdown("*hi*{: }", extensions=["attr_list"])
'<p><em :>hi</em></p>'
```

`<h1 :>` is not valid HTML and our HTML validator in CI rejects the page. An empty list should just mean "no attributes", so I'd expect `<h1>Title</h1>`, `<p>Some paragraph</p>` and `<p><em>hi</em></p>`. Non-empty lists like `{: .note }` work as expected and should keep working.
