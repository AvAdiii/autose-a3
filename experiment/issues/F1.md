title: "WikiLinks: support a display label with `[[Target|Label]]`"
---
The `wikilinks` extension always uses the page name as the link text, so `[[Getting Started]]` becomes a link that says "Getting Started". Most wikis (MediaWiki, Obsidian, GitHub wikis) let you write `[[Page name|text to show]]` to link to a page with different text, and our content team keeps writing that out of habit. Right now it isn't recognized at all and the brackets show up in the output.

What I'd like:

- `[[Getting Started|read the guide]]` links to the same URL as `[[Getting Started]]` but shows "read the guide".
- Whitespace around the `|` shouldn't matter (`[[Getting Started | read the guide]]` is the same thing).
- Everything else (`base_url`, `end_url`, `html_class`, a custom `build_url`) should behave exactly like it does for normal wikilinks; only the visible text changes.
- `[[Page]]` without a pipe keeps working as today.
