title: "toc: let me exclude a heading from the table of contents"
---
Some of our pages have headings that shouldn't be in the table of contents (for example a "Contents" heading right above the `[TOC]` marker, or "Edit this page" footers), but they still need to be real headings with an id so people can link to them.

There's no way to do this today. I'd like to mark such a heading with a class, using `attr_list`:

```markdown
# Guide

## Contents {: .no-toc }

[TOC]

## Install

## Usage
```

With the `toc` and `attr_list` extensions, the TOC should list "Guide", "Install" and "Usage" but not "Contents". The "Contents" heading itself should still be rendered with its id (`id="contents"`) so anchors keep working. The same should apply to `md.toc_tokens`, since our theme builds its sidebar from it.

`no-toc` as the class name would be great (it's what our old static site generator used), but I don't mind if it's configurable.
